# 평가 문항 8 · OOM과 메모리 보호

메모리 누수는 사용이 끝난 객체를 계속 참조해 메모리가 반환되지 않는 상태입니다. 이를 방치하면 사용 가능 메모리가 줄고 reclaim과 swap이 증가하며, 결국 같은 서버의 다른 프로세스까지 느려지거나 커널 OOM Killer의 대상이 될 수 있습니다.

이 앱의 MemoryGuard는 설정한 한계에 도달하면 원인 프로세스를 먼저 종료해 할당 메모리를 반환하고 장애가 서버 전체로 확산되는 것을 막습니다. 실제 로그도 커널 OOM이 아니라 `MemoryGuard`가 PID 1921을 `Self-terminating`했다고 명시합니다.

`MEMORY_LIMIT` 상향은 종료 시점만 늦추는 임시 조치입니다. After에서도 힙이 계속 증가했으므로 근본 해결은 불필요한 참조와 버퍼를 해제하는 것입니다.
