# 평가 문항 15 · 회고

다시 수행한다면 먼저 정상 설정으로 앱의 기본 동작과 로그 형식을 확인한 뒤, 장애별로 환경변수 하나만 변경하겠습니다. 그러면 설정 변경과 결과 사이의 인과관계가 더 명확해집니다.

각 실험 전에 가설과 종료 조건을 적고, 실행 직후 실제 `app.log`에서 타임스탬프와 핵심 메시지를 확인하겠습니다. 특히 CPU After처럼 설정에 따라 에이전트가 다른 시나리오를 선택할 수 있으므로 로그 모양이 다르다는 이유만으로 실패라고 판단하지 않겠습니다.

또한 Deadlock은 로그 정지만으로 단정하지 않고 실행 중 PID 생존, CPU·RSS 정체와 스레드 대기 상태를 먼저 확보하겠습니다. 마지막으로 보고서와 답변에는 예시 수치가 아니라 같은 실행에서 얻은 값만 사용하겠습니다.
