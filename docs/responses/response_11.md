# 평가 문항 11 · 모니터링 개선

현재 `monitor.sh`의 시스템 전체 MEM%만으로는 작은 프로세스의 누수를 조기에 찾기 어렵습니다. 다음 항목을 추가하겠습니다.

- PID별 RSS와 `VmRSS`를 주기적으로 저장
- 현재 값뿐 아니라 `ΔRSS/Δt` 증가율 계산
- 최근 여러 표본이 연속 상승할 때 경고해 순간 변동과 구분
- 설정 한도까지 남은 시간 예측
- 앱 로그의 마지막 갱신 시각과 HTTP 응답 상태 확인
- 경고 단계와 종료 임박 단계를 분리하고 알림 전송

예를 들어 RSS가 5회 연속 증가하거나 증가율 기준으로 10분 안에 한도에 도달할 것으로 예측되면 장애 전에 경고할 수 있습니다.
