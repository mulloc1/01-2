# 평가 문항 10 · Deadlock 원리

Deadlock은 여러 실행 흐름이 서로가 가진 자원을 기다려 누구도 진행하지 못하는 상태입니다.

실제 로그에서 Thread-1은 `Shared_Memory_A`를 획득한 채 `Socket_Pool_B`를 기다립니다. Thread-2는 반대로 B를 획득한 채 A를 기다립니다. 각 자원은 한 스레드만 사용할 수 있으므로 **상호 배제**가 성립하고, 대기 관계가 `Thread-1 → B(Thread-2 보유) → A(Thread-1 보유)`로 연결되므로 **순환 대기**가 성립합니다.

또한 기존 자원을 보유한 채 다른 자원을 기다리는 점유 대기와, 다른 스레드가 락을 강제로 빼앗지 못하는 비선점도 나타납니다. 네 조건이 함께 성립하고 두 `WAITING` 로그 이후 진행이 멈췄으므로 교착으로 판단했습니다.
