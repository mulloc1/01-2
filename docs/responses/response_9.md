# 평가 문항 9 · CPU 과점유와 시스템 보호

CPU는 여러 프로세스가 시간을 나눠 쓰는 자원입니다. 한 프로세스가 지속적으로 코어를 점유하면 같은 서버의 요청 처리, 모니터링, SSH와 장애 복구 작업까지 스케줄링이 늦어질 수 있습니다.

따라서 Watchdog이 원인 프로세스 하나를 종료하거나 제한하면 나머지 서비스와 관리 기능에 CPU 시간을 돌려줄 수 있습니다. 이번 Before에서는 내부 부하가 55.15%까지 올라 `CPU Threshold Violated`로 종료됐고, After에서는 5~10% 사이에서 cooldown하며 생존했습니다.

근본 해결은 busy loop를 이벤트 대기나 sleep/backoff로 바꾸고, 동시 작업 수를 제한된 worker pool로 관리하는 것입니다. 운영 환경에서는 cgroup CPU quota도 함께 적용할 수 있습니다.
